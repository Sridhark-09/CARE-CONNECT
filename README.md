# CARE-CONNECT

**CareConnect: An Offline-First Digital Platform for Community Health Workers**

CareConnect (Community Health Worker Assistance Platform) is an Android app that helps community health workers manage patients and follow-ups in the field, even without internet.

## Features
- **Field Map**: view patient locations and plan visits
- **Offline + Sync**: data is stored locally with Room and synced to Firebase when online
- **Priority Follow-up**: patients grouped as High, Due, and Upcoming
- **Regional Language + Voice**: multilingual interface with voice support
- **AI Chatbot**: health-related assistance
- **Reminders and Reports**: follow-up reminders and summary reports

## Screens
Splash, Login, Dashboard, Patients, Patient Details, AI Chatbot, Reminders, Reports, Settings

## Tech Stack
- Java + XML (Android Studio)
- Room (local database)
- Firebase (backend and sync)

## Setup
1. Clone the repo:
   `git clone https://github.com/Sridhark-09/CARE-CONNECT.git`
2. Open it in Android Studio and let Gradle sync.
3. Add your own `google-services.json` to the `app/` folder.
4. Run on an emulator or device.
